### Astuces
{{ if $appMode }}
- Le navigateur demande le mot de passe ci-dessus (le nom d'utilisateur est ignoré).
- Les données de l'application sont enregistrées dans `~/work`, seul dossier conservé.
- Le menu flottant d'Xpra permet d'envoyer ou de récupérer des fichiers.
- Fermer l'application redémarre le service ; il suffit de recharger la page.
{{ else }}
- La page de connexion demande seulement le mot de passe ci-dessus ; `/logout` pour se déconnecter.
- La session tmux `main` survit à la fermeture de l'onglet : rouvrez le lien pour la retrouver.
- Plusieurs shells dans le même onglet : Alt+t (nouvel onglet tmux), Alt+Entrée / Alt+- (découper), ou les boutons [+] [⫼] [⊟] de la barre d'état.
- `trz` / `tsz <fichier>` : envoyer / récupérer des fichiers via le navigateur.
- Copier : sélection à la souris ; coller : Ctrl+V. Clic droit : menu du terminal (Maj+clic droit : menu du navigateur).
- Tous les raccourcis : Alt+h ou le bouton [?] aide de la barre d'état.
- `agent-session` : un agent IA isolé (sans identifiants, internet via un proxy à liste blanche).
- Ctrl+W ferme l'onglet du navigateur : installez la page en application (menu du navigateur) pour libérer ces raccourcis.
{{ end -}}
{{ else }}
### Tips
{{ if $appMode }}
- The browser asks for the password above (the user name is ignored).
- Application data is stored in `~/work`, the only persistent folder.
- Use Xpra's floating menu to upload or download files.
- Closing the application restarts the service; just reload the page.
{{ else }}
- The login page only asks for the password above; `/logout` to sign out.
- The tmux session `main` survives closing the tab: reopen the link to get it back.
- Several shells in one tab: Alt+t (new tmux tab), Alt+Enter / Alt+- (split), or the [+] [⫼] [⊟] buttons in the status bar.
- `trz` / `tsz <file>`: upload / download files through the browser.
- Copy: select with the mouse; paste: Ctrl+V. Right-click: terminal menu (Shift+right-click: browser menu).
- All shortcuts: Alt+h or the [?] aide button in the status bar.
- `agent-session`: an isolated AI agent (no credentials, internet through an allowlist proxy).
- Ctrl+W closes the browser tab: install the page as an app (browser menu) to free these shortcuts.
{{ end -}}
{{ end -}}
