  TERMINAL SSP CLOUD · AIDE                         (q pour fermer, ↑↓ défiler)

  Onglets et panneaux (tmux)
  ──────────────────────────
  Alt+t              nouvel onglet           (bouton [+] de la barre)
  Alt+Entrée         diviser à droite        (bouton [⫼])
  Alt+-              diviser en dessous      (bouton [⊟])
  Alt+flèches        passer d'un panneau à l'autre (ou clic)
  Alt+1 … Alt+9      aller à l'onglet n      (ou clic sur l'onglet)
  Alt+z              zoomer / dézoomer le panneau
  Alt+w              fermer le panneau
  Alt+h              cette aide              (bouton [?] aide)
  Ctrl+b             préfixe tmux : Ctrl+b puis d = détacher, [ = mode copie…

  La session survit à la fermeture de l'onglet : rouvrez le lien pour la
  retrouver.

  Copier / coller
  ───────────────
  Sélection souris   copie dans le presse-papiers (« Copié » s'affiche)
  Double/triple clic copie le mot / la ligne
  Ctrl+V             coller (aussi Maj+Inser, Ctrl+Maj+V)
  Maj+sélection      sélection du navigateur, sans tmux
  Neovim             y copie dans le presse-papiers, Ctrl+V colle
                     (sélection en bloc : Ctrl+Q au lieu de Ctrl+V)

  Clic droit
  ──────────
  Clic droit         menu du terminal (coller la dernière copie, diviser…)
  Maj+clic droit     menu du navigateur

  Session agent isolée
  ────────────────────
  agent-session      opencode dans un onglet « agent:… » (clic droit aussi),
                     sur une copie sans remote du dépôt courant
                     (~/work/agents/<nom>), utilisateur « agent » : ni
                     identifiants, ni sudo, ni accès à vos fichiers ; internet
                     seulement via un proxy à liste blanche
  agent-session log -f        voir les requêtes (domaines) et appels LLM
  agent-session allow <dom.>  autoriser un domaine (deny pour retirer)
  agent-session fetch <nom>   dans votre dépôt : récupérer ses commits
  agent-session -- bash       un shell dans la session agent
  Ne lancez pas son code dans votre session : il aurait vos identifiants.

  Thème
  ─────
  Alt+m / [◐]        basculer entre thème clair et sombre (mémorisé par
                     le navigateur ; Neovim suit)
  theme clair|sombre la même chose en ligne de commande ; theme defaut
                     revient au thème d'Onyxia

  Fichiers
  ────────
  Glisser-déposer    déposer des fichiers sur la page : ils arrivent dans
                     le dossier du panneau actif (même si vim y tourne)
  [↑] / clic droit   « Envoyer des fichiers ici » : choisir les fichiers
  [↓] / clic droit   « Télécharger des fichiers… » : choisir avec fzf
                     (Tab pour en sélectionner plusieurs)
  trz / tsz <fich.>  la même chose en ligne de commande (-d : dossiers)
  Le choix de fichiers et le téléchargement demandent Chrome ou Edge ;
  Firefox permet seulement le glisser-déposer.
  ~/work             seul dossier conservé au redémarrage

  Applications web (serveur lancé dans le terminal)
  ────────────────
  Cliquer sur l'URL affichée (http://localhost:8000/...) l'ouvre dans le
  navigateur via le proxy du terminal : <adresse du terminal>/proxy/8000/
  ports              liste les ports en écoute avec leur lien
  /absproxy/8000/    garde le chemin, pour les applications réglées avec ce
                     chemin de base (Vite --base, Streamlit
                     --server.baseUrlPath, Jupyter --ServerApp.base_url)
  N'ouvrez ainsi que des applications de confiance : elles partagent
  l'adresse du terminal.
